# Translations

i18n is optional and file-based. Create a folder named `i18n` next to the `.goi`
files, put one JSON file per language in it, and a design can translate any
text with `t(...)`.

```
myapp/
  Main.goi
  i18n/
    en.json
    tr.json
    de.json
```

The folder is detected automatically: every `.json` file is a language, named
after its file (`tr.json` is the `tr` catalog). A design without the folder keeps
working, and `t("some.key")` then shows the key itself.

## The catalog format

Keys are strings, and a nested object is read with dots:

```json
{
	"welcome_message": "Hoşgeldiniz",
	"settings": {
		"theme": "Tema",
		"language": "Dil"
	},
	"welcome_with_name": "Hoşgeldin %s"
}
```

## Using a key

```goi
Text {
	text: t("welcome_message")
}

Text {
	text: t("settings.theme")
}

Text {
	text: t("welcome_with_name", "Kaan")
}
```

Arguments after the key fill the entry's Go `fmt` verbs, exactly like
[`formatf`](../syntax.md): `%s` text, `%d` a number, `%v` anything. Without
arguments the entry is used as written, so a stray `%` is safe.

## Choosing the language from Go

```go
app.SetLanguage("tr")            // default: the desktop's language
app.SetFallbackLanguage("en")    // default: the desktop's language
```

The lookup order for every key is:

1. the language set with `SetLanguage`,
2. the language set with `SetFallbackLanguage`,
3. the key itself, so a missing translation is visible rather than blank.

That applies per entry: a language can be complete for one screen and fall back
for another. A language code the design does not ship (say `de` with no
`de.json`) therefore shows the fallback's text.

The desktop reports a code such as `en-US`; `en.json` is still found, because a
region code matches its base language.

## Reading the language in a design

`app.language` is the active language and `app.systemLanguage` is the desktop's
preference. `app.language` follows the desktop until `SetLanguage` overrides it,
so a design can highlight the current language or show a fallback hint.

```goi
Text {
	text: app.language
}
```

From Go, `App.Language()` and `App.SystemLanguage()` report the same two
values; `Window.Language()` and `Window.SystemLanguage()` do too.

## Hot reload

Editing a `.json` file under `i18n/` reloads the catalogs and repaints on the
next frame, with no relayout and no loss of app state. A missing or malformed
catalog is reported through `App.OnError` and leaves the previous strings in
place.
